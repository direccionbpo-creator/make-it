Tips for better results

  • High-contrast, simple shapes cut the cleanest lines.
  • Raise "Remove small details" to avoid tiny stray paths the laser would otherwise try to cut.
  • Always verify the millimeter dimensions in your laser software before cutting.

Frequently asked questions

Can I set the exact cutting size?

Yes — set width and height in millimeters and the exported file matches that physical size.

SVG or DXF — which should I use?

Both carry the same paths. Use whichever your laser cutter’s software imports more reliably; DXF is common for industrial/CAM software, SVG for hobby lasers and design tools.

Does it remove the background automatically?

Yes, background removal is on by default and can be toggled off if your image already has a transparent or solid background.

Can this generate different colors for different cut/score passes?

Not yet — this tool outputs a single set of cut paths. Multi-pass color-coded layers are on the roadmap.
