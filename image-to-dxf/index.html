Convert Image to DXF

Upload a PNG, JPG, WEBP or SVG and this tool traces it into vector contours and exports a real DXF file (AutoCAD 2000/LWPOLYLINE format). The generated DXF contains geometry that can be imported into compatible CAD/CAM software — machine-specific toolpaths and G-code still need to be configured for your machine, tool and material.

Tips for better results

  • Simple, high-contrast shapes produce the cleanest, most reliable contours.
  • Use "Include inner contours" to keep or drop interior holes depending on your toolpath needs.
  • Always check units and scale after importing into your CAD/CAM software.

SVG vs DXF for laser cutting

SVG

Common in design and web tooling; widely supported by hobby laser cutters and vinyl plotters.

DXF

The standard exchange format for CAD/CAM and CNC software — often the safer choice for professional or industrial workflows.

Frequently asked questions

Will this DXF work with any CNC machine?

The generated DXF contains geometry that can be imported into compatible CAD/CAM software. Machine-specific toolpaths and G-code still need to be configured for your machine, tool and material — this tool does not generate G-code.

What DXF version does this export?

AutoCAD 2000 (AC1015) using LWPOLYLINE entities, a widely supported baseline for CAD/CAM import.

Can I get SVG instead of DXF?

Yes — every DXF download here has a matching SVG download built from the same paths.

Does the DXF preserve real-world dimensions?

Yes. The coordinates are scaled to the width/height (mm) you set before export.
