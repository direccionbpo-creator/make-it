How Make It works

Upload an image, choose what to make, and download a real fabrication file. Every processing step runs in your browser using canvas and WebGL — no upload, no account, no install.

1

Upload

Drop a PNG, JPG, WEBP or SVG, choose a file, or paste an image from your clipboard. The image is decoded straight into an in-memory canvas — it is never sent to a server.

2

Choose

Pick a manufacturing method: 3D print, laser cut, laser engrave, CNC, vinyl cutter or stencil. Each shares the same underlying image pipeline with different defaults and outputs.

3

Adjust

Background removal, threshold, detail, smoothing and real-world dimensions update the live preview instantly as you move each slider.

4

Download

The download button builds the real output file — binary STL, zipped 3MF, SVG, DXF, PDF or PNG — from the exact geometry shown in the preview.

What actually happens to your image

Every tool follows roughly the same pipeline: the image is converted to grayscale, optionally cleaned with automatic background removal, thresholded into a black/white shape, and cleaned of small speckles. For vector outputs (SVG, DXF, laser, CNC, vinyl, stencil), that shape is traced into polygon contours, simplified and smoothed. For 3D outputs, the shape (and, in Relief mode, its grayscale detail) is converted into a height grid and meshed into a solid, watertight object.

Every one of those steps is plain JavaScript running against a <canvas> element in your browser. There is no server-side image processing anywhere on this site.

Where it can't be 100% local

It can't, today — every tool on this site processes entirely client-side. If that ever changes for a future tool, this page and the tool's own page will say so explicitly rather than assume you'll notice.
