Convert Image to CNC-Ready Contours

Upload a logo or drawing and this tool vectorizes it into clean outer and inner contours sized to real millimeters. The generated DXF/SVG contains geometry that can be imported into compatible CAM software — it does not generate G-code, since toolpaths depend on your machine, tool and material.

Tips for better results

  • Turn off inner contours if your CAM software only needs the outer boundary.
  • Simplify aggressively for router bits that cannot follow fine detail.
  • Double-check the imported scale in your CAM software before cutting.

Frequently asked questions

Does this generate G-code?

No. It generates clean vector contours (DXF/SVG) that you import into CAM software, which then generates toolpaths and G-code for your specific machine, tool and material.

Can I exclude interior holes from the contour?

Yes — turn off "Include inner contours" to keep only the outer boundary.

Will the DXF work with my CAM software?

The DXF uses the common AutoCAD 2000/LWPOLYLINE format most CAM software can import, but always verify compatibility with your specific software.

Can I set the physical cutting size?

Yes — width and height in millimeters, matched exactly in the exported file.
